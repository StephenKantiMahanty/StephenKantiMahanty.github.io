013D position & velocity

The sensors report at different times, so I update the navigation state as each reading arrives.

02Covariance & diagnostics

I track the uncertainty and rejected readings alongside the estimate so I can see how it responds.

Updating covariance

Each correction changes the covariance as well as the position estimate. I use Joseph form to preserve its structure after each scalar measurement.

Acoustic ranges

The beacons report distance, while the filter estimates coordinates. So I linearize that distance at the predicted position and apply each reading at its sensor's cadence.

Checking the results

I wanted the comparison to reflect the filter itself. Every version receives the same seeded observations, and you can export each mission step to check the results.

Model specification & references +

120 s mission; 0.1 s propagation; six states in east/north/depth coordinates. Continuous white acceleration with spectral density q = 0.02 m²/s³. Acoustic σ = 0.5 m; pressure σ = 0.08 m; Doppler σ = 0.045 m/s. Scalar normalized innovation squared above 9 is rejected. The 95% ellipsoid uses the three-dimensional χ² threshold 7.8147 and the full position covariance eigensystem.

Known attitude and global-frame inertial acceleration are assumed. IMU noise has σ = 0.025 m/s² and fixed bias [0.006, −0.004, 0.0015] m/s². Orientation and sensor bias are not estimated. Beacon positions are known, noise streams are independent, and updates have no latency. Cross-current changes actual acceleration and is observed by the inertial sensor. The vehicle and seabed are procedural; this is a portfolio simulation inspired by underwater robotics.
