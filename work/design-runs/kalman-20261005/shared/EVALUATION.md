# Frozen evaluation

Mandatory gate: all PROJECT_BRIEF features and actual correct numerical filter, independent implementation, Secret integration and regression verification. Unknown checks are unknown, not passes. No fabricated user testing or benchmarks.

Weighted subjective scoring after gate: visual quality/engagement 30%, learning clarity/usability 30%, functionality/numerical correctness 20%, accessibility/responsiveness 10%, maintainability/performance 10%. Same seed 42 and nominal/dropout/current/bias tasks. Same viewport 1440x900,390x844,320x740. Compare: explain one correction; run dropout and identify growing uncertainty; replay identical sensor data at different R; reset/reach mission end; keyboard control use. Performance measured only if actual measurements exist.

Each delivery includes actual commands/results, files, preview instructions, rationale and limitations. Fresh independent reviewers inspect usability/visuals, functionality/accessibility, technical quality after candidates complete. Integration selects a coherent foundation and specific compatible improvements rather than merging everything. Final tests must be rerun.
