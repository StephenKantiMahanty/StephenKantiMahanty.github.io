Audience: curious portfolio visitors and robotics learners. Build a striking, useful interactive Kalman-filter simulation, linked as fourth project from Secret. Static HTML/CSS/JS, no backend/build/CDN requirements. Existing projects and Worker remain functional. Use kalman/ for the standalone activity. Preserve original site conventions outside it. Mandatory journeys: launch from Secret; understand truth vs measurement vs estimate; play/pause/step/reset a mission; change assumed Q/R separately from actual noise; compare repeatable runs; observe dropout/current/bias; understand predict/update and confidence vs actual error; use mobile and keyboard.

Implement a genuine linear Kalman filter with position/velocity and known acceleration, either one-dimensional underwater depth or independent planar axes. Use fixed time steps and seeded noise. Position fixes are simulated processed localization fixes, not raw sonar bearings/ranges or GPS underwater. DVL, if present, measures velocity. Ground truth never enters filter updates. Use valid Q consistent with disturbance model and Joseph covariance correction. Explain units, variance vs standard deviation, model limitations and any deliberately mismatched scenarios. Label RoboSub-inspired, not official course/scoring.

Features: visually compelling underwater robot scene with distinct labeled trace shapes; uncertainty band/ellipse correctly labeled; live numerical telemetry and RMSE for raw measurements/filter/dead reckoning; scenario presets (nominal, dropout, current, sensor bias); controls for actual sensor noise and assumed measurement/process noise; seed replay; teaching panel/worked predict-correct example and learner prompt; comparison of same data with changed tuning; finite mission endpoint and meaningful summary. Manual sensor toggling optional if preset dropout clearly works. All mandatory features apply equally to all designs.

Controls native/keyboard-operable, visible focus, 44px touch targets, no page overflow at 320px, no forced autoplay, honor reduced-motion, readable semantic text equivalent to plots, no per-frame screen-reader announcements. No-JS explanatory fallback. Never intercept unrelated page keys. Keep dependencies optional: distinctive custom CSS/SVG/canvas is encouraged; external UI libraries only if justified and installed locally.

Replay deterministic with same seed and controls; tuning does not change measurement stream. Covariance finite, symmetric, PSD over long run. Verify meaningful fixed-seed RMSE, no requirement to always improve. Test all site regressions; update three-card test to four and footer. Syntax and diff checks.
