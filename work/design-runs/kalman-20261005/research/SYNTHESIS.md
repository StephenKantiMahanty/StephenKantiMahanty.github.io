# Parallel research synthesis

Three independent research agents completed before the brief freeze:
- Kierkegaard: user journeys and comparable teaching activities. Recommended guided prediction questions, identical sensor data for tuning comparisons, failure diagnosis, and truthful sensor models.
- Lovelace: visual design/accessibility. Recommended deep-sea mission control with explanatory notebook panels, shape/pattern trace encoding, explicit uncertainty semantics, semantic telemetry and reduced-motion/phone controls.
- Locke: technical feasibility. Verified static site architecture and Worker fallback routing; recommended DOM-independent 2-state axis filtering, fixed timestep, seeded noise, Joseph covariance update, analytical numerical fixture and long-run PSD checks.

Research conclusions are design hypotheses; no learner studies were performed. Competition context is sourced from official RoboNation handbook tasks, with simplified navigation and fictional lab scoring. Acoustic processed position fixes avoid misrepresenting raw ranges as linear coordinates. Core math follows Welch/Bishop; visually explained filter reference by Tim Babb.

Primary/reference links are preserved in shared/PROJECT_BRIEF.md. All three candidates receive the same scope and acceptance gate, with different design priorities. UI libraries are optional; local static assets and no installation burden preferred for this repository.
