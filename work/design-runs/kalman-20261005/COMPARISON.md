## Integration plan

Use cinematic's coherent scene, fixed-step model and diagnostic chart. Retain clarity-inspired plain-language predict/listen/trust wording and optional equations. Retain workbench-inspired scrub/end inspection, Match actual noise and a short learner prediction/feedback. Preserve one consistent setting policy: tuning changes pause and rewind on the same recorded data; world changes regenerate and clear baseline. Scrubbing pauses at an inspected time, and every control announces physical units.

Required final fixes: R/q aria-valuetext with variance units; scrubber seconds-valuetext; all outputs explicitly silent; nominal help reflects current world/assumptions; Match sets exact variances; plot bounds include every displayed trace and band; invalid covariance/tuning input rejection; beginner anchor and collapsed optional math; no-JS actions disabled. No swapping rival numerical cores/defaults or indiscriminate merging. Reverify new controls, nominal/dropout/current/bias endpoint/replay, baseline lifecycle, keyboard/mobile/layout/no-JS and full numerical/regression suite. Final source goes to final worktree and then reviewed files into original portfolio. No publishing.
